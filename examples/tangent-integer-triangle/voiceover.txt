这道题看起来是三个整数的求和问题，但绝对不能随便猜数。因为这三个数分别来自一个三角形的三个内角，我们要先利用内角和把它们限制住。

已知三角形 ABC 的三个内角是 A、B、C，三个角的正切值都为整数。要求这三个正切值的和。注意，既然题目说正切值为整数，就意味着它们都必须有定义。

三个正切值求的是和，交换 A、B、C 的名称并不改变结果。所以我们不妨按照大小排列，设 A 小于等于 B，小于等于 C。研究最小角往往比直接枚举整数容易。

为什么最小角 A 不超过六十度呢？因为如果连最小角都大于六十度，另外两个角只会更大，三角形内角和就会超过一百八十度。因此最小角 A 一定小于等于六十度。

A 是一个大于零且不超过六十度的锐角。正切函数在锐角区间内严格递增，所以 tan A 大于零，同时不超过 tan 六十度，也就是根号三。根号三小于二。

现在同时知道 tan A 是正整数，并且严格小于二。这样的整数只有一，所以 tan A 必须等于一。因为 A 在锐角范围内，正切等于一对应四十五度，于是 A 等于四十五度。

已经知道 A 是四十五度。根据三角形内角和，另外两个角 B 与 C 的和，就是一百八十度减四十五度，等于一百三十五度。这给后面的正切和角公式提供了条件。

这里不能直接默认 B 和 C 是锐角。若 C 大于九十度，而 A、B 均不小于四十五度，则内角和超过一百八十度；若 C 等于九十度，tan C 没有定义。两种情况都不允许。所以 B、C 必须是锐角。

现在把 tan B 记为 b，tan C 记为 c。因为 B 和 C 是锐角，且 B 小于等于 C，所以 b 与 c 都是正整数，并且 b 小于等于 c。接下来就可以用代数方法求解。

我们已经得到 B 加 C 等于一百三十五度。而一百三十五度在第二象限，它的正切值是负一。所以 tan 括号 B 加 C 括号等于负一，这就是联立整数条件的关键。

正切和角公式告诉我们，tan 括号 B 加 C 括号，等于 b 加 c 除以一减 b 乘 c。这个值又等于负一。因为这里的正切有定义，所以分母一减 bc 不等于零，可以安全移项。

把等式两边乘上一减 bc，就得到 b 加 c 等于 bc 减一。然后移项，得到 bc 减 b 减 c 等于一。这个式子看上去有两个未知数，但可以通过补一项变成乘积。

在 bc 减 b 减 c 等于一的两边同时加一，左边就能拆成 b 减一乘以 c 减一，右边等于二。这样我们把三角函数方程，变成了两个整数因子的配对问题。

由于 b 与 c 都至少是一，并且两个因子的乘积是二，所以 b 减一和 c 减一都必须是正整数。二的正整数因子只能是一和二。根据 b 小于等于 c 的顺序，就得到 b 减一等于一，c 减一等于二。

于是三个内角的正切值分别等于一、二、三。题目要求的和就是一加二加三，答案等于六。注意这个答案不是猜中的，而是由角度范围和整数条件共同唯一确定的。

做这类题时要避开两个错误。第一，正切函数不能在跨越九十度的区间里直接谈整体单调性；第二，两个角之和的正切，并不等于两个正切值直接相加，必须使用完整的和角公式。

现在复盘完整思路：先排序找到最小角，用三角形内角和与正切单调性锁定它的正切值；接着利用另外两角的和套用正切和角公式；最后对整数方程进行因式分解。

请再判断一个类似的问题：如果三角形三个内角的正切值分别为一、二、四，这样的三角形存在吗？请先根据刚才的条件想一想，不要只凭这三个数都是正整数就做判断。

三角形的三个内角只要正切都有定义，就满足三个正切之和等于三个正切之积。对于一、二、四，左边是一加二加四等于七，右边是一乘二乘四等于八。七不等于八，因此这样的三角形不存在。

做完后请记住一种思考方式：先让几何条件限制角度，再让函数性质限制数值，最后利用整数条件缩小可能性。你可以试着独立解释，为什么最小角的正切一定等于一。
